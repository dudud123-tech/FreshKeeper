# 앱 등록 전 확인사항

오늘까지야를 Google Play 등 앱 스토어에 등록하기 전에 확인할 항목입니다.
작업이 끝난 항목은 `[ ]`를 `[x]`로 변경합니다.

## 앱 기본 정보

- [ ] 최종 앱 이름을 `오늘까지야`로 통일
- [ ] 앱 아이콘과 스플래시 이미지 최종 확인
- [ ] Android 패키지명 `com.palchonajae.freshkeeper` 유지
- [ ] 앱 버전과 Android `versionCode` 증가
- [ ] 스토어용 앱 설명, 스크린샷, 카테고리 준비
- [ ] 고객 문의용 이메일 또는 연락처 준비
- [ ] Play 스토어 출시 후 Kakao Developers에 스토어 URL 추가

## 이용약관 및 개인정보

- [ ] 서비스 이용약관 작성 및 공개 URL 준비
- [ ] 개인정보처리방침 작성 및 공개 URL 준비
- [ ] 수집하는 계정 정보와 사용 목적 명시
  - Google 또는 카카오 계정 식별자
  - 이메일을 실제로 수집하는 경우 이메일
  - 닉네임과 프로필 사진
- [ ] 회원 탈퇴 또는 계정 연결 해제 방법 제공
- [ ] 서버에 저장되는 상품 분류·제외 설정의 보관 및 삭제 기준 명시
- [ ] 앱에서 요청하는 사진, 카메라, 알림 권한의 사용 목적 확인

### 현재 사용하지 않는 카카오 기능

- `간편가입`
  - 카카오 동의 화면에서 오늘까지야 자체 이용약관까지 함께 동의받아야 할 때 검토합니다.
  - 일반적인 카카오 로그인만 구현할 때는 필요하지 않습니다.
- `고급`
  - 자동 로그인, 특정 계정 선택, 추가 동의 등 특별한 로그인 동작이 필요할 때만 설정합니다.
  - 현재 로그인 구현에는 필요하지 않습니다.
