# 오늘까지야 비공개 테스트 안내문 초안

## 테스터에게 보낼 짧은 안내

안녕하세요.

소비기한 관리 앱 `오늘까지야` 비공개 테스트를 부탁드립니다.

테스트 링크로 참여한 뒤 앱을 설치하고, 실제 영수증이나 주문내역 캡처로 상품 등록을 한 번 이상 테스트해 주세요.

확인해 주면 좋은 것:

- 앱 설치가 잘 되는지
- 영수증 또는 주문내역 사진 등록이 되는지
- 상품이 보관함에 저장되는지
- 소비기한 알림 설정이 이해되는지
- 화면이 잘리거나 버튼이 안 눌리는 곳이 있는지
- 앱이 갑자기 종료되는지

문제가 있으면 캡처 화면과 함께 알려주세요.

감사합니다.

## 테스터 체크리스트

1. 앱 설치
2. 알림 권한 허용
3. 사진등록으로 영수증 또는 주문내역 캡처 선택
4. 상품 후보 확인
5. 보관함에 저장
6. 보관함에서 상품 수정/삭제 테스트
7. 설정에서 알림 기준 변경
8. 앱 종료 후 다시 실행

## Play Console 비공개 테스트 준비물

- 테스터 이메일 12명 이상
- 비공개 테스트 트랙 생성
- AAB 파일 업로드
- 릴리즈 노트 작성
- 테스트 참여 링크 공유

## 릴리즈 노트 초안

오늘까지야 비공개 테스트 첫 배포입니다.

- 영수증/주문내역 사진으로 상품 등록
- 실물 영수증 형광펜 선택
- 직접 상품 등록
- 보관함 관리
- 임박/만료 알림
- 가족 공유

실제 사용 중 불편한 점이나 인식이 이상한 영수증이 있으면 알려주세요.

## 테스트 중 수집할 피드백

- 사용한 이미지 종류: 종이 영수증 / 모바일 영수증 / 쿠팡·컬리 주문내역 / 직접등록
- 상품명이 잘 추출되었는지
- 잘못 추출된 항목
- 직접 제외한 항목
- 화면이 잘리거나 버튼이 눌리지 않는 기기 설정
- 알림 수신 여부
