# Google Play 데이터 보안 답변 초안

이 문서는 Play Console의 데이터 보안 양식을 작성할 때 참고하기 위한 초안입니다.

## 앱에서 수집하거나 공유하는 데이터

### 개인 정보

선택적 Google 로그인 사용 시 이메일 주소, 표시 이름, Google 계정 식별자,
프로필 이미지 URL이 수집될 수 있습니다. 사용 목적은 계정 관리와 사용자별 상품
분류·제외 설정 동기화입니다. 로그인하지 않으면 이 정보는 수집하지 않으며,
전화번호는 수집하지 않습니다.

### 사진 및 동영상

수집 여부: 앱 기능에서 접근함

사용 목적:

- 영수증 촬영
- 주문내역 캡처 선택
- 상품 이미지 등록

주의:

- 사용자가 직접 선택하거나 촬영한 이미지만 처리합니다.
- 기본적으로 이미지는 기기 내 기능 처리를 위해 사용합니다.
- 서버 업로드 여부는 현재 구현 상태 확인 후 Play Console에 정확히 입력해야 합니다.

### 앱 활동 / 앱 정보 및 성능

수집 여부: 제한적으로 수집 가능

사용 목적:

- OCR 결과 품질 개선
- 앱 버전별 오류 분석

전송될 수 있는 값:

- 앱 버전
- OCR 줄 수
- 선택/제외 결과
- 요청 식별자
- 앱 설치별 임의 식별자
- 상품 분류 제안값과 사용자가 최종 등록한 카테고리, 보관 방법, 소비기한

### 사용자 생성 콘텐츠

수집 여부: 기능 사용 시 수집 가능

예:

- 상품명
- 소비기한
- 보관 방식
- 카테고리
- 구매 링크
- 가족 공유 보관 목록

사용 목적:

- 보관함 관리
- 가족 공유
- 임박/만료 알림

## 데이터 공유

제3자 광고 SDK를 아직 붙이지 않았다면 광고 목적 공유는 없음으로 처리합니다.

Cloudflare에 저장되는 학습 개선/가족 공유 데이터는 앱 기능 제공 및 품질 개선 목적의 서버 처리로 설명합니다.

## 데이터 암호화

전송 중 암호화:

- HTTPS 사용

사용자가 데이터 삭제를 요청할 수 있는가:

- 예
- 앱 내 삭제 또는 개발자 문의를 통한 서버 데이터 삭제 요청 가능

## 권한 사용 목적

### 카메라

영수증, 주문내역, 상품 사진을 촬영하기 위해 사용합니다.

### 사진/미디어

갤러리에서 영수증, 주문내역 캡처, 상품 이미지를 선택하기 위해 사용합니다.

### 알림

소비기한이 임박했거나 만료된 상품을 사용자에게 알려주기 위해 사용합니다.

### 정확한 알림 예약

사용자가 설정한 시간에 하루 알림을 예약하기 위해 사용합니다.

## 출시 전 점검 필요

### 광고 SDK

광고를 실제로 붙이기 전까지는 Play Console의 광고 포함 여부를 신중히 선택해야 합니다.

광고 SDK를 추가하면 데이터 보안 양식도 다시 업데이트해야 합니다.
