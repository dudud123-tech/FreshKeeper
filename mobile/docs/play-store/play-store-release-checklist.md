# 오늘까지야 Play Store 출시 체크리스트

마지막 업데이트: 2026-06-21

상태 표기:

- `대기`: 아직 시작 전이거나 외부 승인을 기다리는 상태
- `진행중`: 작업을 시작했지만 완료되지 않은 상태
- `완료`: 작업 완료
- `확인필요`: 판단 또는 추가 확인이 필요한 상태
