# 오늘까지야 개인정보처리방침

시행일: 2026년 7월 4일

오늘까지야는 사용자의 개인정보를 중요하게 생각합니다. 본 개인정보처리방침은 오늘까지야 앱이 어떤 정보를 수집하고, 어떻게 사용하며, 어떻게 보호하는지 설명합니다.

## 1. 수집하는 정보

오늘까지야는 기본적으로 로그인 없이 사용할 수 있습니다. 사용자가 선택적으로
Google 로그인을 이용하면 상품 분류와 제외 설정을 계정에 연결해 다른 기기에서도
이어갈 수 있습니다. 개인 보관함 정보는 별도의 가족 공유 기능을 사용하지 않는 한
사용자의 기기 안에 저장됩니다.

앱 기능 제공을 위해 다음 정보가 처리될 수 있습니다.

- 사용자가 등록한 상품명, 카테고리, 보관 방식, 소비기한, 등록일
- 사용자가 직접 저장한 구매 링크
- 사용자가 선택한 상품 이미지
- 영수증 또는 주문내역 이미지에서 인식된 OCR 텍스트
- 사용자가 선택하거나 제외한 OCR 결과
- OCR로 인식된 상품명과 서버가 제안한 카테고리, 보관 방법, 소비기한
- 사용자가 최종 등록한 카테고리, 보관 방법, 소비기한
- 사용자가 상품 후보에서 제외한 상품명
- 로그인 전 사용자 구분을 위한 앱 설치별 임의 식별자
- Google, 카카오 또는 네이버 로그인 시 해당 제공자가 전달하는 계정 식별자,
  이메일, 표시 이름, 프로필 이미지
- 로그인 상태 유지를 위한 세션 정보
- 알림 설정 정보
- 가족 공유 코드, 그룹 소유자·참여자 정보 및 공유된 보관 목록
- 가족 공유에 사용자가 명시적으로 업로드한 압축 상품 사진

## 2. 사진 및 카메라 사용

오늘까지야는 영수증, 주문내역, 상품 사진을 등록하기 위해 카메라와 사진 접근 권한을 요청할 수 있습니다.

사진은 사용자가 직접 선택하거나 촬영한 경우에만 앱에서 처리됩니다. 앱은 사용자가 선택하지 않은 사진을 임의로 읽거나 업로드하지 않습니다. 가족 공유에 동의한 경우 상품 사진은 낮은 해상도로 압축되어 Cloudflare R2에 저장될 수 있습니다.

## 3. 알림 사용

오늘까지야는 소비기한이 임박했거나 만료된 상품을 알려주기 위해 알림 권한을 요청할 수 있습니다.

알림은 사용자가 설정한 시간과 기준에 따라 기기에서 예약됩니다.

## 4. 서버로 전송될 수 있는 정보

사용자가 학습 개선 데이터 전송을 켠 경우, 상품 추출 품질 개선을 위해 다음 정보가 서버로 전송될 수 있습니다.

- OCR로 인식된 텍스트 줄
- 사용자가 상품으로 선택한 항목
- 사용자가 제외한 항목
- 앱 버전
- 처리 결과 식별자

학습 개선 데이터는 상품 추출 정확도 개선을 위한 목적으로만 사용됩니다.

OCR 상품의 카테고리, 보관 방법 및 소비기한을 안내하고 같은 상품의 반복 수정을
줄이기 위해, 인식된 상품명과 앱 설치별 임의 식별자가 분류 서버로 전송됩니다.
사용자가 상품을 등록하면 서버의 제안값과 사용자가 최종 선택한 값이 저장될 수
있습니다. 앱 설치별 식별자는 이름, 전화번호 또는 이메일을 포함하지 않습니다.

Google, 카카오 또는 네이버 로그인을 선택한 경우 기존 기기의 상품 분류 및 제외
설정이 로그인 계정에 연결될 수 있습니다. 계정 식별에는 각 로그인 제공자가
제공하는 고유 식별자를 사용하며, 로그인 세션 토큰은 원문이 아닌 해시 형태로
서버에 저장됩니다.

## 5. 가족 공유

가족 공유는 로그인한 사용자가 데이터 저장 및 사진 업로드 안내에 동의한 경우에만 사용할 수 있습니다. 상품명, 카테고리, 보관 방식, 소비기한과 그룹 구성 정보는 Cloudflare D1에 저장되고, 사용자가 등록한 압축 상품 사진은 Cloudflare R2에 저장될 수 있습니다.

공유 코드를 입력한 로그인 사용자는 그룹 참여자로 등록됩니다. 그룹 소유자는 그룹과 공유 데이터를 삭제할 수 있고, 참여자는 그룹에서 나갈 수 있습니다. 공유 코드는 신뢰할 수 있는 가족 또는 동거인에게만 전달해야 합니다.

가족 공유 그룹 안에서는 구성원을 구분하기 위해 소셜 로그인에서 제공된 표시 이름과 프로필 사진, 그룹 내 역할이 다른 구성원에게 표시됩니다. 이메일 주소는 가족 구성원에게 표시하지 않습니다.

## 6. 제3자 제공

오늘까지야는 법령에 따른 요구가 있거나 사용자가 명시적으로 동의한 경우를 제외하고, 개인정보를 제3자에게 판매하거나 임의로 제공하지 않습니다.

다만 앱 기능 제공을 위해 다음 외부 서비스가 사용될 수 있습니다.

- Cloudflare: 로그인·학습 개선 데이터, 가족 공유 상품 정보(D1) 및 압축 사진(R2) 저장
- Google: 선택적 Google 로그인, 앱 배포, 알림, 권한 관리
- Kakao: 선택적 카카오 로그인
- NAVER: 선택적 네이버 로그인

## 7. 데이터 보관 및 삭제

기기 안에 저장된 상품 정보는 사용자가 앱에서 삭제하거나 앱 데이터를 삭제하면 제거됩니다.

가족 공유 그룹은 마지막 사용 후 90일 동안 활동이 없으면 상품 정보와 사진을 자동 삭제합니다. 그룹 소유자가 앱에서 그룹을 삭제하거나 계정을 삭제하는 경우에도 해당 그룹의 상품 정보와 사진이 삭제됩니다. 참여자가 그룹에서 나가면 참여자 연결 정보가 삭제됩니다.

서버로 전송된 계정별 상품 설정과 가족 공유 데이터는 앱의 계정 및 서버 데이터 삭제 메뉴 또는 공개된 계정 삭제 안내에 따라 삭제할 수 있습니다. 로그아웃은 해당 기기의 로그인 세션만 해제하며 계정을 삭제하지 않습니다.

## 8. 아동 개인정보

오늘까지야는 아동을 대상으로 하지 않으며, 고의로 아동의 개인정보를 수집하지 않습니다.

## 9. 보안

오늘까지야는 전송되는 데이터를 보호하기 위해 HTTPS 통신을 사용합니다. 다만 어떤 전송 및 저장 방식도 절대적인 보안을 보장할 수는 없습니다.
