# 오늘까지야 Play Store 등록 문구 초안

## 앱 이름

오늘까지야

## 짧은 설명

영수증과 주문내역으로 소비기한을 등록하고, 임박 상품을 알림으로 챙겨보세요.

## 긴 설명

오늘까지야는 냉장고와 식료품 보관함에 있는 상품의 소비기한을 쉽게 관리하는 앱입니다.

종이 영수증, 모바일 영수증, 온라인 주문내역 캡처에서 상품명을 인식해 보관 목록에 등록할 수 있고, 직접 등록도 지원합니다. 등록한 상품은 소비기한이 가까워지면 임박 상품으로 표시되며, 하루 한 번 알림으로 확인할 수 있습니다.

주요 기능

- 영수증/주문내역 사진에서 상품 후보 추출
- 실물 영수증은 형광펜으로 필요한 상품만 직접 선택
- 상품별 소비기한, 보관 방식, 카테고리 관리
- 임박/만료/오늘 만료 상품 확인
- 하루 한 번 임박/만료 알림
- 가족에게 임박 상품 공유
- 보관함 상품에 구매 링크 저장

이런 분께 좋아요

- 장 본 뒤 식재료 소비기한을 자주 놓치는 분
- 냉장고에 뭐가 있는지 한눈에 보고 싶은 분
- 유통기한/소비기한 임박 상품을 먼저 먹고 싶은 분
- 영수증이나 쿠팡/컬리 주문내역 캡처로 빠르게 등록하고 싶은 분

오늘까지야는 사용자의 식품 낭비를 줄이고, 냉장고를 조금 더 가볍게 관리할 수 있도록 돕습니다.

## 검색 키워드 참고

소비기한, 유통기한, 냉장고 관리, 식품 관리, 영수증 OCR, 장보기, 냉장고 알림, 유통기한 알림, 식재료 관리

## 카테고리 후보

- 라이프스타일
- 식음료
- 도구

추천: 식음료 또는 라이프스타일

## 스크린샷 구성 추천

1. 홈 화면: 이번 주 먼저 먹을 것, 보관 중인 상품 요약
2. 상품 등록: 사진등록/직접등록 화면
3. 영수증 인식 결과: 선택된 상품과 저장 버튼
4. 보관함: 검색/필터/상품 카드
5. 설정: 알림 기준과 가족 공유
