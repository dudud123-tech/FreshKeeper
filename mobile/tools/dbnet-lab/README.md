# DBNet Text Detection Lab

영수증 OCR 좌표 보정을 위해 DBNet 계열 텍스트 검출 모델을 먼저 검증하는 실험 도구입니다.

목표는 OCR을 대체하는 것이 아니라, ML Kit OCR이 읽은 텍스트에 더 정확한 좌표를 붙이는 것입니다.

## 사용 순서

1. DBNet 계열 ONNX 모델을 준비합니다.
   - 권장 입력: `1 x 3 x H x W` 이미지 텐서
   - 권장 출력: 텍스트 확률맵 `1 x 1 x h x w`
2. `dbnet-lab.html`을 브라우저로 엽니다.
3. 모델 파일과 영수증 이미지를 선택합니다.
4. `검출 실행`을 누릅니다.
5. 결과 박스가 이미지 위에 보이면 품질을 확인합니다.
6. `JSON 저장`으로 박스 결과를 보관합니다.

## 판정 기준

- 종이 영수증의 상품명 줄과 가격 줄이 실제 텍스트 위에 안정적으로 잡히는지 봅니다.
- 바코드, 버튼, 배경 무늬 같은 비텍스트 영역이 너무 많이 잡히면 후처리 기준을 조정해야 합니다.
- 텍스트 박스가 잘 잡히면 Android TFLite 모듈로 이식합니다.

## 앱 이식 흐름

현재 앱 코드는 이미 다음 우선순위를 받을 준비가 되어 있습니다.

```text
DBNet/TFLite 박스
→ OpenCV 텍스트 라인 박스
→ ML Kit 기본 OCR 좌표
```

앱에서 DBNet 박스가 적용되면 `boxSource`가 `dbnet-text-line`으로 표시되고, 보라색 박스로 보입니다.

## 주의

DBNet 모델마다 출력 형태가 조금씩 다릅니다. 이 HTML은 가장 흔한 probability map 형태를 우선 지원합니다.
모델 출력이 다르면 후처리 코드를 모델에 맞게 조금 바꿔야 합니다.
